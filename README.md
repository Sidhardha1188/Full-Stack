## Running the code
- HTML / CSS / JS: open the `index.html` file in a browser.
- Node and Express: `npm install`, then `npm start` (or the script named in the folder's README).
- React: `npm install`, then `npm run dev`.
- MongoDB folders need a local MongoDB server.
