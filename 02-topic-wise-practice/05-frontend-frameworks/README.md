# React Practice

- [react-components-props](react-components-props): coding club directory. Covers object props, default props, `children` and JSX passed as props, callback props from child to parent, and lists with keys.
- [state-management-hooks](state-management-hooks): timed quiz. Covers `useReducer` for the quiz flow, `useState`, `useEffect` with cleanup, `useMemo`, `useCallback`, `useRef`, and a custom `useCountdown` hook.

Run in each folder: `npm install`, then `npm run dev`.
