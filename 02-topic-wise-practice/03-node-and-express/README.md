# Node.js and Express Practice

| File | Topic | Command | Port |
|---|---|---|---|
| `basic-http-server.js` | `http` module: serving a file with `fs`, JSON responses, reading a POST body from the request stream | `npm run http` | 5100 |
| `express-middleware-demo.js` | Logger, `express.static`, maintenance mode, a rate limiter (5 requests / 10 s), a validation middleware factory, 404 and error handlers | `npm run middleware` | 5101 |
| `rest-api-crud.js` | Canteen menu API with GET (with filters), POST, PUT, PATCH and DELETE | `npm run crud` | 5102 |

Run `npm install` first.
