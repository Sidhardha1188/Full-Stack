# Lab Task 3a: Flexbox, Positioning and Media

## Aim
Show Flexbox layouts, CSS positioning with z-index, and embedding a map, audio and video.

## What the page covers
- Flexbox: a navbar, equal-height cards with `flex-wrap`, `order` and `align-self`, and centring an element.
- Positioning: a badge with `absolute` inside a `relative` card, a `relative` offset, overlapping layers with `z-index`, a `fixed` back-to-top button and a `sticky` navbar.
- Media: a Google Maps `<iframe>`, `<audio>` with two sources, and a muted `<video>`.

## How to run
Open `src/index.html`. Put `song.mp3` and `clip.mp4` in `src/media/` to play the audio and video.
