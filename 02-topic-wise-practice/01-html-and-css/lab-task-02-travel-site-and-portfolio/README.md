# Lab Task 2: Travel Website and Portfolio

## Aim
Build a travel website and a personal portfolio using external CSS, Flexbox, Grid and media queries.

## Files
- `src/travel-site/`: "Godavari Trails" (Papikondalu, Konaseema, Srisailam, Horsley Hills). Trip cards use Flexbox, the season table uses zebra rows, and the enquiry form uses a two-column CSS Grid.
- `src/portfolio/`: two-column Grid layout with a sticky sidebar, an education timeline and skill bars.

## How to run
Open each `index.html`. Narrow the window below 650px (travel site) or 760px (portfolio) to see the mobile layout.
