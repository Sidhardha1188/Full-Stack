# Lab Task 1: HTML Tags and Resume

## Aim
Use the HTML tags covered in class on one page, and write a resume using only HTML.

## Files
- `src/index.html`: text-level tags (kbd, samp, var, cite, address, time...), nested and styled lists, figure/figcaption, details/summary, progress/meter, a marks table with thead/tbody/tfoot, rowspan and colspan, and a form with fieldset, datalist, file and hidden inputs.
- `src/resume.html`: resume using headings, a description list for education and a table for skills.

## How to run
Open `src/index.html`. The resume is linked from the navigation.
