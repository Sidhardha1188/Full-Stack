# Lab Task 3b: JavaScript Arrays and Functions

## Programs
1. Second largest element in one pass, without sorting
2. Rotating an array left or right by k places
3. Prime numbers in an array with `filter` and a helper function
4. `find`, `findIndex`, `some`, `every` and `includes`
5. Merging two sorted arrays (two-pointer method)
6. Splitting into chunks and flattening a nested array with recursion
7. IIFE, currying and rest parameters

## How to run
Open `src/index.html` and pick a program from the dropdown (or "Run all"), or run `node src/arrays-functions.js`.
